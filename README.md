A personal corner of the internet built to explore technology, creativity, infrastructure, and curiosity.

This website started as a late-night experiment and slowly turned into a space where I can document projects, thoughts, rabbit holes, and the things I’m learning along the way.

Instead of feeling like a traditional portfolio, I wanted it to feel more alive — like a quiet workstation someone actually uses.

---

## features

* terminal-inspired UI
* atmospheric dark aesthetic
* responsive design
* subtle ASCII-inspired visuals
* integrated Hashnode blog feed
* lightweight and self-hostable
* minimal animations and ambient effects
* dino game because why not

---

## stack

* Next.js
* Tailwind CSS
* TypeScript
* Hashnode Rss feed 
* Cloudflare Tunnel

---

## philosophy

I like personal websites.

Not algorithm feeds.
Not engagement farming.
Not corporate-looking portfolio templates.

Just small independent spaces on the internet where people build things, write openly, and experiment freely.

This site is my version of that.

---

## blog

Posts are fetched dynamically from Hashnode and usually revolve around:

* Linux
* self-hosting
* homelab experiments
* networking
* infrastructure
* learning in public
* technology and internet culture

